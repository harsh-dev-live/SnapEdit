# 📸 SnapEdit

A fast, lightweight **Snapseed-inspired photo editor** built with pure HTML, CSS and JavaScript.

Edit, enhance, rotate, flip and export your photos directly in your browser — with no installation or backend required.

## 🚀 Try SnapEdit

### 👉 [🖼️ CLICK HERE TO START EDITING](https://harsh-dev-live.github.io/SnapEdit/index.html)

**Open the editor directly and start editing your photo.**

## ✨ Features

* 📂 Image upload
* 🖼️ Local browser-based editing
* ☀️ Brightness adjustment
* ◐ Contrast adjustment
* 🎨 Saturation adjustment
* 🌡️ Warmth adjustment
* 🔍 Sharpness adjustment
* ↶ Rotate left
* ↷ Rotate right
* ↔️ Flip image
* 🖤 Black & White
* 🟤 Sepia
* 🔄 Reset edits
* 💾 Download edited image
* 📱 Responsive interface
* 🔒 Privacy-focused local processing

## 🔐 Privacy First

SnapEdit processes your photos directly in your browser.

Your images are **not uploaded to a server** for editing.

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* FileReader API

No framework or backend is required.

## ⚡ Run Locally

Clone the repository:

```bash
git clone https://github.com/harsh-dev-live/SnapEdit.git
```

Then open:

```text
index.html
```

in your browser.

No installation or build process is required.
